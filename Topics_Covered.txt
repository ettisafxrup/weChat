 weChat -- Let's make Friends
 Terminal-based C++ OOP Chat Application
 Cross-platform: Windows (MSVC / MinGW / g++) | Linux | macOS
 
 OOP Concepts Covered:

  [✅] Classes & Objects         -- Heart of this Project
  [✅] Array of Objects          -- vector<User>, vector<Room>, vector<Message>
  [✅] Object References         -- AppState&, User&, Room&
  [✅] Memory Allocation         -- new AppState() / delete in singleton
  [✅] Default Constructor       -- all classes
  [✅] Parameterised Constructor -- all classes
  [✅] Copy Constructor          -- Message, User, Room, Person hierarchy
  [✅] Destructors               -- all classes; virtual in hierarchy
  [✅] Function Overloading      -- findRoom(str)/findRoom(int), sendMessage overloads, showMenu overloads
  [✅] Operator Overloading      -- ==, <, +, +=, <<, >> (cin/cout)
  [✅] Type Conversion           -- explicit operator string() in User, Room, Message
  [✅] Static Members            -- totalMessages, totalRooms, totalAccounts, onlineCount, instance
  [✅] friend Functions          -- operator<< / operator>> in Message, User, Person, Room
  [✅] cin / cout overloading    -- operator>> (Message), operator<< (Message, User, Person, Room)
  [✅] Single Inheritance        -- Contact <- Person,  AccountHolder <- Person
  [✅] Multiple Inheritance      -- User <- Contact + AccountHolder
  [✅] Multilevel Inheritance    -- Admin <- User <- Contact/AccountHolder <- Person
  [✅] Hierarchical Inheritance  -- Room <- BaseRoom,  AnnouncementRoom <- BaseRoom
  [✅] Virtual Base Class        -- virtual Person in Contact & AccountHolder (diamond fix)
  [✅] Compile-time Polymorphism -- function overloading, operator overloading
  [✅] Runtime Polymorphism      -- virtual displayInfo(), getRole(), getType()
  [✅] Pointer to Derived Class  -- BaseRoom* br = room; state.displayRoomInfo(br)
  [✅] Abstract Base Class       -- Person, BaseRoom, ISerializable (pure virtuals)
  [✅] Virtual Functions         -- displayInfo(), getRole(), getType(), getMemberCount()
  [✅] Templates                 -- Payload<T>, FileManager::appendToFile<T>, readFromFile<T>
  [✅] File Handling             -- fstream + atomic rename in FileManager
